# Governance

Maintainer material for the INK project. None of it ships in the npm package.

## Decisions

Ratified project decisions, numbered and append-only. A decision record states
what was decided, why, what it costs and what it forecloses. It is not a
specification: where a decision has normative consequences, the spec named in
the record owns them.
